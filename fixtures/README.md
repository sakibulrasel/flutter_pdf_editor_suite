# PDF test fixtures

Shared test corpus for all four packages. Tests read these files with paths
relative to the package root, for example `../fixtures/pdf/form_classic.pdf`.

## `pdf/` — generated corpus

Every file in `pdf/` is generated by [`tool/generate_fixtures.py`](../tool/generate_fixtures.py)
with ReportLab, pypdf, pikepdf, Pillow and qpdf, so it is free to redistribute.
[`pdf/manifest.json`](pdf/manifest.json) describes each file and lists what
`PdfPreflight` should report for it; `pdf_engine_core/test/pdf_preflight_test.dart`
checks every entry.

| Group | Files | What they cover |
| --- | --- | --- |
| Plain documents | `text_single_page`, `text_multi_page`, `text_letter_landscape`, `mixed_page_sizes`, `rotated_pages`, `unicode_embedded_font`, `images_jpeg_png`, `blank_page` | Page sizes, `/Rotate`, embedded TrueType subsets, JPEG and PNG-with-alpha images |
| AcroForms | `form_classic`, `form_filled`, `form_incremental_update`, `form_incremental_xref_stream`, `form_hierarchical_names`, `form_xfa_only` | All field types, values written by another tool, classic and xref-stream incremental updates, inherited field attributes, XFA |
| Structure | `text_object_streams`, `form_object_streams`, `text_linearized`, `pdf_version_2_0`, `flate_content_stream` | Compressed object streams and xref streams (the PDF 1.5+ layout Acrobat and Word use), linearization, PDF 2.0 header, binary stream data |
| Security | `encrypted_aes256_user_password`, `encrypted_aes128_owner_only`, `encrypted_rc4_40`, `form_encrypted` | AES-256, AES-128 with empty user password and restricted permissions, legacy RC4 |
| Broken | `not_a_pdf`, `truncated`, `junk_before_header`, `broken_xref_offsets` | Non-PDF data, cut-off files, junk before the header, wrong xref offsets |

Passwords: `encrypted_aes256_user_password.pdf` user `user123` / owner `owner123`;
`encrypted_rc4_40.pdf` user `user` / owner `owner`; the others have an empty user
password and owner password `owner123`.

To regenerate (needs `pip install reportlab pypdf pikepdf pillow` and `qpdf`):

```sh
python3 tool/generate_fixtures.py
```

## `real_world/` — files from real producers

Synthetic files cannot cover every quirk of real producers. Add PDFs made by
Adobe Acrobat, Microsoft Word, Google Docs, Chrome "Save as PDF", LibreOffice,
scanners and government or bank forms to `real_world/`, but **only files you are
allowed to redistribute** (your own documents, public-domain forms, or files
under an open licence). Record each one in `real_world/SOURCES.md` with where it
came from, its licence and what it is meant to test.
