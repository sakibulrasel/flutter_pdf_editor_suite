# Editable PDF Save

Goal: preserve real AcroForm fields and save an updated PDF that remains editable in Acrobat and other viewers.

## Scope

- [x] Keep original `/AcroForm` structure instead of flattening pages to images
- [x] Update field dictionaries in the original PDF
- [x] Preserve widget annotations and field object references
- [x] Keep exported PDFs editable after reopening

## Phase A - Field Write-Back

- [x] Write `/V` for text fields
- [x] Write `/V` and `/AS` for checkboxes
- [x] Write `/V` and `/AS` for radio groups
- [x] Write `/V` for combo boxes
- [x] Write `/V` for single-select list boxes
- [x] Write `/V` for multi-select list boxes
- [ ] Define save behavior for signature fields

## Phase B - Appearance Updates

- [ ] Regenerate visible appearances for edited text fields
- [ ] Regenerate visible appearances for checkboxes
- [ ] Regenerate visible appearances for radio buttons
- [ ] Regenerate visible appearances for combo boxes
- [ ] Regenerate visible appearances for list boxes
- [ ] Regenerate visible appearance for signature fields
- [ ] Handle default appearance `/DA` safely
- [ ] Handle appearance streams `/AP` without breaking common viewers

## Phase C - PDF Structure

- [ ] Parse and update xref tables safely
- [x] Support incremental save where possible
- [ ] Update trailer information correctly
- [ ] Preserve unrelated objects and annotations
- [ ] Avoid corrupting object numbers and references
- [ ] Handle PDFs with multiple pages and many widgets

## Phase D - Compatibility

- [x] Reopen saved editable PDF in this app and detect fields again
- [ ] Verify saved editable PDF in Adobe Acrobat
- [ ] Verify saved editable PDF in mobile viewers
- [ ] Verify saved editable PDF in browser viewers
- [ ] Test with simple AcroForm PDFs
- [ ] Test with real-world PDFs generated by ReportLab and Acrobat

## Phase E - UX

- [x] Add separate `Save Editable PDF` action in the example app
- [x] Keep `Export Flattened PDF` as a separate action
- [x] Show clear messaging when editable save is unsupported for a given file
- [x] Fall back to flattened export only when editable save cannot be preserved

## Notes

- This is different from the current flattened export path.
- The current exporter in `flutter_pdf_editor` produces a visual final PDF, not a live AcroForm PDF.
- Editable save should be treated as a separate implementation track with its own tests and compatibility checks.
