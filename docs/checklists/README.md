This folder breaks the roadmap into separate phase checklists.

1. [Phase 0 - PDF Basics](./phase-0-pdf-basics.md)
2. [Phase 1 - Render a PDF Page](./phase-1-rendering.md)
3. [Phase 2 - Viewer Widget](./phase-2-viewer-widget.md)
4. [Phase 3 - Overlay Editing](./phase-3-overlay-editing.md)

Target MVP:

- [ ] Open PDF from file and bytes
- [ ] Render pages
- [ ] Zoom and scroll
- [ ] Tap to add text, signature, and checkmark overlays
- [ ] Save a new PDF with overlays burned in
